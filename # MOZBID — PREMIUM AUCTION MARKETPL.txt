# MOZBID — PREMIUM AUCTION MARKETPLACE
## MASTER UI/UX DESIGN PROMPT

### 1. ROLE

Act as a world-class Lead Product Designer, Senior UI/UX Designer and Senior Frontend Engineer specialized in luxury automotive marketplaces, premium auction platforms and international ecommerce experiences.

Your mission is to design and implement a premium online auction marketplace called **MozBid**, targeting the Mozambican market.

Use the uploaded reference image as the primary visual reference.

The objective is to recreate its visual identity, composition, atmosphere and design language, transforming it into a sophisticated online auction experience.

This is NOT a generic ecommerce website.

It must look like an exclusive international auction marketplace.

---

### 2. CORE DESIGN DIRECTION

The design must preserve the visual characteristics of the reference:

- Deep black background.
- Luxury dark interface.
- Orange and golden lighting.
- Large cinematic automotive photography.
- Elegant white typography.
- Refined transparent surfaces.
- Dark translucent search panels.
- Subtle gradients.
- Premium product presentation.
- Minimalist navigation.
- Carefully controlled visual effects.

The result should communicate:

- Exclusivity.
- Trust.
- Competition.
- Luxury.
- Security.
- Professionalism.
- Real-time activity.

Do not replace this identity with a generic dashboard design.

### 3. COLOR SYSTEM

Use this palette as the foundation:

```css
:root {
  --background: #080808;
  --background-secondary: #101010;
  --surface: #151515;
  --surface-elevated: #202020;

  --primary: #F5A000;
  --primary-hover: #FFB52E;
  --primary-dark: #B87500;

  --text-primary: #FFFFFF;
  --text-secondary: #B8B8B8;
  --text-muted: #777777;

  --success: #22C55E;
  --danger: #EF4444;
  --warning: #F59E0B;

  --border: rgba(255,255,255,0.09);

```

Orange must be the main interactive accent.

Use gold sparingly for premium highlights.

Black must dominate the interface.

Avoid excessive colours, especially purple, bright blue and unnecessary gradients.

### 4. HOMEPAGE — HERO SECTION

Recreate the composition of the uploaded reference image.

#### Navigation

Create a slim transparent navigation bar positioned at the top.

Left:
- MozBid logo.
- Minimal orange auction-inspired symbol.

Center:
- Home.
- Explore Auctions.
- Categories.
- How It Works.
- Membership.
- About Us.

Right:
- Search icon.
- Notifications.
- Watchlist.
- User profile.
- Login/Register or account menu.

The navigation should be elegant, compact and discreet.

#### Main hero

Use a large cinematic automotive photograph positioned on the right side.

The image should feature a premium sports car, preferably with orange or golden lighting.

The left side must contain the main marketing message.

Headline:

"Discover Exclusive Auctions"

Second line:

"Bid With Confidence."

Supporting text:

"Explore exceptional products, compete in real-time auctions and win exclusive deals through one powerful marketplace."

Primary button:

"Explore Auctions →"

Secondary button:

"Start Selling"

Use large refined typography with strong visual hierarchy.

The headline should be approximately 48–64px on desktop.

Use a subtle black-to-transparent overlay to maintain text readability.

The hero should feel cinematic, luxurious and spacious.

### 7. LIVE AUCTION EXPERIENCE

Create a section called:

"Ending Soon"

- Current bid.
- Time remaining.

### 15. TYPOGRAPHY

Use Inter or Manrope.

Typography must establish a clear hierarchy:

- Large cinematic hero headings.
- Medium section headings.
- Clear product titles.
- Strong numerical prices.
- Small, readable metadata.

The current bid must be one of the most visually prominent elements on auction cards and auction detail pages.

### 16. RESPONSIVE DESIGN

Desktop:
Preserve the full cinematic composition.

Tablet:
Reduce hero typography and adapt the floating search panel.

Mobile:
- Compact navigation.
- Large hero headline.
- Optimized product image.
- Stacked search filters.
- Two-column or single-column product grid depending on screen width.
- Sticky bidding action on auction detail pages.
- Touch-friendly controls.

Never allow horizontal overflow.

### 17. TECHNOLOGY

Implement using:

- Quasar Framework.
- Vue 3.
- TypeScript.
- Composition API.
- Pinia.
- Vue Router.
- SCSS.
- Vite.

Use reusable components and a centralized design system.

The first development version must use mock data clearly separated from API services.

The initial application backend will use Node.js and Express, with SQLite as the first database.

Keep the frontend independent of the database technology.

Future migration from SQLite to MongoDB must not require redesigning the interface.

### 18. QUALITY REQUIREMENTS

- Pixel-conscious implementation of the visual reference.
- Professional spacing and alignment.
- Consistent typography.
- High-quality imagery.
- Accessible contrast.
- Functional navigation.
- Functional filters.
- Functional auction cards.
- Responsive layouts.
- Reusable Vue components.
- No dead buttons.
- No generic AI-generated dashboard appearance.
- No inconsistent design between pages.

### 19. FINAL OBJECTIVE

Deliver a complete and visually sophisticated auction marketplace.

The homepage must immediately communicate the quality of an international luxury auction platform.

The auction detail page must make bidding the central interaction.

The buyer, seller and administrator experiences must share the same premium identity.

**The final design must preserve the uploaded reference image's visual language while transforming the experience into a complete, modern and professional online auction marketplace for Mozambique.**
